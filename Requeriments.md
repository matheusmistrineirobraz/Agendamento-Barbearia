## Agendamento-Barbearia

# Problemas a serem resolvidos
- Visibilidade de clientes;
- Horários disponíveis;
- Funcionários
- Pagamentos;
- Serviços;
- Histórico de Acessos(clientes/Funcionários);
- Planos de Cortes;

# Usuários do Sistema
- Administrador
- Cliente
- Funcionário
- Metodo de Pagamento

# RF - Requisitos Funcionais
- RF01 - Cadastro/Exclusão de Clientes;
- RF02 - Cadastro/Exclusão de Horários;
- RF03 - Cadastro/Exclusão de Funcionário;
- RF04 - Cadastro/Exclusão de Funções;
- RF05 - Edição de Cliente;
- RF06 - Edição de Funcionário;
- RF07 - Edição de Horário;
- RF08 - Consulta Cliente;
- RF09 - Consulta Funcionário;
- RF10 - Cadastro Planos;
- RF11 - Consulta Planos;

# RNF - Requisitos Não funcionais

- RNF01 – Segurança: O sistema deve exigir autenticação para acesso às funcionalidades restritas e impedir que usuários acessem informações que não possuem permissão para visualizar.
- RNF02 – Controle de acesso: O sistema deve possuir diferentes níveis de acesso para Administrador, Cliente e Funcionário, permitindo que cada perfil tenha acesso somente às suas respectivas funções.

- RNF03 – Proteção de dados: Os dados pessoais dos clientes, funcionários, pagamentos e históricos devem ser armazenados de forma segura, evitando acesso ou alteração não autorizada.

- RNF04 – Senhas: As senhas dos usuários devem ser armazenadas utilizando métodos seguros de criptografia/hash, não podendo ser armazenadas em texto puro.

- RNF05 – Desempenho: As operações principais do sistema, como cadastro, consulta e edição de clientes, horários e serviços, devem apresentar resposta em tempo adequado, preferencialmente em até 3 segundos em condições normais.

- RNF06 – Disponibilidade: O sistema deve estar disponível durante o horário de funcionamento da empresa, com o mínimo possível de interrupções.
  
- RNF07 – Responsividade
O sistema deve funcionar adequadamente em computadores, tablets e smartphones, adaptando sua interface aos diferentes tamanhos de tela.

- RNF08 – Compatibilidade: O sistema deve funcionar nos principais navegadores atuais, como Google Chrome, Microsoft Edge, Mozilla Firefox e Safari.

- RNF09 – Integridade dos dados: O sistema deve garantir que informações como horários, clientes, serviços, pagamentos e consultas sejam armazenadas de forma consistente, evitando duplicidades e informações incorretas.

- RNF10 – Backup: Os dados do sistema devem possuir cópias de segurança periódicas para possibilitar a recuperação das informações em caso de falhas.
